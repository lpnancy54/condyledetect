# CondyleDetect

Application d'analyse des condyles mandibulaires.

## Lancer l'application SaaS

```bash
python app.py
```

Puis ouvrir `http://localhost:5000` pour déposer un fichier STL, lancer l'analyse
et récupérer les exports JSON / STL marqués.

## Application desktop

```bash
python condyle_analyzer_gui.py
```

L'analyseur GUI reste disponible pour un usage local.
